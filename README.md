# react-native-secure-webview

Opinionated Fabric-native WebView for controlled authentication and checkout flows

## Installation


```sh
npm install react-native-secure-webview
```


## Usage


```js
import { SecureWebviewView } from "react-native-secure-webview";

// ...

<SecureWebviewView color="tomato" />
```
